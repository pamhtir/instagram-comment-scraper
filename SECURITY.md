# Security policy

## Sensitive material

Never commit or share `.env`, cookies, browser-profile folders, credentials, debug HTML, HAR files, client URLs, unredacted screenshots, runtime logs, or raw/processed client data. If any secret or session material is committed, revoke it, remove it from Git history, and rotate the affected credential.

## Responsible operation

Use a dedicated browser profile and only collect data you are authorized to access. Do not bypass access controls, verification, CAPTCHAs, privacy settings, or rate limits. Minimize retained data, define a deletion date, anonymize public samples, and follow applicable platform terms, contracts, privacy requirements, and laws.

## Reporting

For a public repository, use GitHub private vulnerability reporting instead of opening an issue containing sensitive details.
