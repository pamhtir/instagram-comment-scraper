# Roadmap: completed now vs later projects

## Included in this portfolio release

- Professional English repository structure and proof-of-work README.
- Post/Reel URL handling, comment-surface isolation, incremental loading, targets, fast mode, stable stop logic, multilingual fallbacks, data cleaning, CSV/XLSX automation, per-run logging, actionable errors, tests, CI, security guidance, client checklist, demo production plan, and anonymized sample deliverables.

## Requires live validation before claiming complete

- Repeatable acceptance on at least two Posts and two Reels.
- Measured username/comment pairing accuracy and recall.
- Confirmation of English UI plus one Vietnamese fallback run.
- Real GIF/video and screenshot after the matrix passes.
- Confident reply/parent mapping. The current fields are conservative rather than guessed.

## Best saved for later projects

- A separate YouTube adapter as the next portfolio project.
- TikTok and Facebook adapters only after each can be tested and maintained independently.
- Shared `BaseScraper` plug-in architecture after a second mature adapter exists.
- Official API integration for authorized high-volume work.
- Proxy pools, distributed workers, multi-account orchestration, OCR, sentiment analysis, dashboards, databases, and cloud deployment.

Adding multiple adapters will not slow one Instagram run if loaded on demand, but it greatly increases maintenance, authentication, policy, selector, test, and support complexity. Do not add platforms merely to make the README look larger.
