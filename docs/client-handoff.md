# Client-first handoff checklist

## Before collection

- Confirm ownership/authorization, target URLs, content visibility, fields, replies, approximate volume, deadline, output format, locale, and acceptance sample.
- Agree on limitations, retry policy, data retention/deletion date, and secure delivery channel.
- Define success as visible records collected, not an unsupported guarantee of every platform comment.

## Before delivery

- Manually spot-check at least 20 username/comment pairs.
- Confirm no UI labels, blank records, duplicates, or wrong source URL.
- Open CSV with UTF-8 characters and both Excel sheets.
- Scan the run log for warnings; redact it if shared.
- Remove credentials, browser data, raw debug material, and unrelated client files.
- Deliver a short manifest: target, UTC run time, collected count, invalid count, duplicate count, known gaps, filenames, and deletion date.
