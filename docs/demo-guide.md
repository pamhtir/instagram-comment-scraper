# 45–60 second portfolio demo

## Before recording

- Use an authorized public test Post/Reel and a dedicated demo profile.
- Hide bookmarks, notifications, email, usernames not needed for proof, `.env`, profile paths, and cookies.
- Prepare one clean terminal and close unrelated applications.
- Pass the manual test matrix first.

## Shot list and narration

1. **0–6s — README:** “This workflow turns visible Instagram comments into client-ready CSV and Excel.”
2. **6–15s — command:** Run a plain Reel URL with `--max-comments 50`.
3. **15–28s — browser:** Show the requested Reel staying in place while the comment dialog opens and scrolls.
4. **28–36s — terminal:** Show unique counts, clean completion, and output paths.
5. **36–50s — Excel:** Open `Summary`, then `Comments`; show filters, source URL, UTC timestamp, and clean text.
6. **50–60s — close:** “The project includes validation, tests, logs, privacy controls, and documented limitations.”

Record 1920×1080, crop tightly, use large terminal text, and export a 10–20 second GIF plus an unlisted full video. Put `demo.gif` and `sample-output.png` in `assets/`, then embed them near the top of README. Do not manufacture a browser run; real proof is more valuable than decorative animation.
